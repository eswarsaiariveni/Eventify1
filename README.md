# 🎟️ Eventify – Online Event Ticket Booking System

## 📌 About the Project

Eventify is a web-based Online Event Ticket Booking System that allows users to explore upcoming events, view event details, and book tickets online. It provides a simple and user-friendly platform for managing event bookings.

## 🎯 Objectives

- Develop an easy-to-use online event booking platform.
- Provide secure user registration and login.
- Display event details, dates, venues, and ticket prices.
- Allow users to book multiple tickets online.
- Store booking information and manage ticket availability.

## ✨ Key Features

- User Registration and Login
- Event Listing and Search
- Event Details and Ticket Prices
- Online Ticket Booking
- Automatic Total Amount Calculation
- User Profile Management
- MySQL Database Integration

## 🗄️ Database

Database Name: `eventdb`

Main Tables:
- `users` – Stores user information.
- `events` – Stores event details and ticket availability.
- `bookings` – Stores ticket booking information.

## ⚙️ How to Run the Project

1. Install JDK and IntelliJ IDEA.
2. Install MySQL and Apache Tomcat 10.1.
3. Import the project into IntelliJ IDEA as a Maven project.
4. Configure the MySQL database connection.
5. Create the required database and tables.
6. Configure Tomcat in IntelliJ IDEA.
7. Run the project using the Tomcat server.
8. Open the application in your browser.
